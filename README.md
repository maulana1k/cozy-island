Classification: INTERNAL

# Cozy Island

A small, calm 3D island to wander around, themed as a student scout camp: a headquarters
marquee, patrol tents, a food tent, a first-aid tent, a guard post, a farm and a flagpole.
Open a tent flap with E and walk in: the top is sliced away so you can see inside. Poke at things and nudge your fellow
scouts. There is nothing to win or finish.

## Run it

```bash
npm install
npm run dev
```

Then open the address it prints (normally http://localhost:5173).

## Controls

| Key | What it does |
|---|---|
| W A S D or arrow keys | Move |
| Shift | Run |
| Space | Hop |
| E | Use the thing in front of you |
| M | Open or close the map |
| N | Sound on or off |
| F | Join in with what the camp is doing |
| X | Sit down or stand up |
| C | Free look on or off |
| J | Open or close the journal side bar |
| Esc | Pause menu |
| Drag the mouse | Turn the camera |
| Scroll | Zoom |

## Things to try

Light the lanterns and campfires, open doors, ring the bell, sit on a log, shake a tree,
shoo the chickens, pet the cat and the sheep, visit the windmill, and bump into a villager.
Climb the hill to the summit camp and ride the flying fox down to the beach.
Press J for the journal of things to find.

## Notes

- Nothing is saved; every visit starts in the late afternoon.
- A full day takes about 8 minutes. Lanterns and windows light up at night.
- `npm test` runs the rule tests. `npm run build` makes a production build in `dist/`.
